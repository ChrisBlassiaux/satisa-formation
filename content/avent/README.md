# Fichiers du calendrier de l'Avent

Un fichier par case : `JJ-titre-court.pdf` (jour sur deux chiffres, sans accent ni espace), moins de 4 Mo.

Après avoir déposé le fichier, indiquer son nom avec `fichier` sur la ligne du jour dans `lib/aventCases.ts`.

Ne jamais placer ces fichiers dans `public/` : ils seraient téléchargeables avant leur jour.
